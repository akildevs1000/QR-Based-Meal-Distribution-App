# QR Meal Server — Electron desktop wrapper

Wraps the Laravel backend in a tray app for non-technical Windows users. Customer double-clicks an installer, gets a tray icon with Start/Stop/Logs controls, and the backend runs as a child process. Scanners on the LAN connect to `http://<pc-ip>:8000/api/...`.

## How to run in dev mode

The dev mode uses your **system PHP** (the one we set up at `C:\Users\SERVER\.config\herd-lite\bin\php.exe`) and the repo's `backend/` folder directly — no bundling.

1. Stop any running `php artisan serve` (otherwise port 8000 is taken):
   ```powershell
   # Find and kill any process on port 8000
   netstat -ano | findstr :8000
   taskkill /F /PID <pid>
   ```
2. From `electron/`:
   ```powershell
   npm run dev
   ```
3. A tray icon appears (look in the system tray, may be hidden under the `^` arrow). Right-click for the menu. Left-click opens the Logs window.
4. The backend is now reachable at `http://localhost:8000` and `http://<your-lan-ip>:8000`.

## How the dev → packaged path works

| Concern | Dev mode | Packaged |
|---|---|---|
| PHP binary | Your system `php.exe` (on PATH or via `PHP_BIN` env var) | Bundled at `<install>/resources/php/php.exe` |
| Backend folder | Repo's `../backend/` directly | Copied from `<install>/resources/backend` to `%APPDATA%/QR Meal Server/backend/` on first launch (so Laravel can write storage/) |
| `.env` | Whatever you have in `backend/.env` | Generated by the first-run setup window |

## Build the installer

```powershell
# 1. Copy PHP runtime into resources (one-time, manual for now)
robocopy "C:\Users\SERVER\.config\herd-lite\bin" "resources\php" /E /XD bin.bak

# 2. Make sure backend has fresh vendor/ for production
cd ..\backend
composer install --no-dev --optimize-autoloader
cd ..\electron

# 3. Build
npm run build
```

Output: `electron/dist/QRMealServer-Setup-0.1.0.exe`

The installer:
- Asks where to install (defaults to `C:\Program Files\QR Meal Server`)
- Adds Start Menu + Desktop shortcuts
- Adds a Windows Firewall inbound rule for port 8000
- Removes both on uninstall

## Customer install experience

1. Customer runs `QRMealServer-Setup-0.1.0.exe` → standard NSIS wizard
2. App launches → first-run setup window asks for Postgres credentials
3. Click **Test connection** to verify, then **Save & start**
4. App writes `.env`, runs `key:generate` and `migrate`, starts the server
5. Tray icon shows the server is running, with the LAN IPs scanners can connect to
6. On reboot, customer launches from Start Menu / Desktop shortcut → no setup needed second time
